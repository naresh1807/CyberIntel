# Observation contracts

SQLite observations are unique by `(scan_id, kind, key)`. Repository.save is the
central normalization envelope. It serializes concurrent merges and rejects an
empty/oversized key. Caller attributes cannot replace canonical key or source.

Every row contains key, asset_id (SHA-256 of kind + NUL + key), source (latest
collector), sources (all contributors), first_seen, last_seen, collected_at,
confidence and observation_status. Timestamps are UTC. IDs are stable across
scans for the same fact key; first/last dates describe observations within that
scan, not a global inventory. Evidence references include relative path, SHA-256
and bytes when a raw artifact is retained. Some native responses retain only a
body hash: no full body exists in storage to open. Historical confidence does
not establish current service availability.

| Kind | Canonical key | Meaning / core fields |
| --- | --- | --- |
| assets | normalized host/IP | Domain, host or IP inventory; host, active_verified |
| subdomains | normalized hostname | Passive concrete name; host, verified_current |
| dns | host:TYPE:SHA256(value) | host, type, value, ttl where available; TXT hash only |
| http | sanitized absolute URL | status_code, safe headers, TLS, body hash, truncation |
| ports | IP:protocol:port | host, port, protocol, state when observed |
| services | IP:protocol:port | Nmap service/product/version/CPE, evidence |
| technologies | URL:header or IP:protocol:port | Banner or service technology evidence; lifecycle assessment |
| urls | sanitized absolute URL | Endpoint/link; verified, extraction attribution |
| apis | sanitized absolute URL | Observed, candidate or documented API; methods, parameter_names |
| javascript | sanitized absolute URL | Hash, source-map candidates, redacted pattern counts |
| historical | sanitized absolute URL | Archived observation; verified_current flag |
| findings | URL:check or CVE:CPE | Classification, confidence, confirmed_vulnerability=false for recon |
| relationships | left:relation:right (native separator is `\|`) | Typed from_node/to_node/relation; not a new authorized target |
| errors | diagnostic sequence within scan | Safe code, message, source; no arbitrary exception payload |

Imported DNS uses the same key as native DNS. Ports from native Nmap and Naabu
share keys when IP/protocol match; providers with unknown transport keep that
uncertainty instead of inventing TCP. Engine JSONL data is unverified, bounded,
and scope filtered. An invalid input row contributes no partial records.

Technology observations at separate endpoints remain separate facts; no
heuristic merges a banner and a CPE into a confirmed installed package. Alias
mapping/backport applicability remains a release follow-up. Parameter names
appear in API metadata and graph relationships; values are discarded. Graph
node prefixes preserve entity type and directions. Endpoint, host and DNS IP
discovery never automatically authorize subsequent active operations.

Risk metadata distinguishes UNKNOWN, NO_KNOWN_LIFECYCLE_ISSUE,
KNOWN_EOL_CONDITION and POTENTIALLY_AFFECTED. The first green-like state concerns
only the upstream lifecycle check; none is a security certification. Header
configuration reviews and JS patterns require validation. Confirmed findings
are not generated by these reconnaissance paths.
